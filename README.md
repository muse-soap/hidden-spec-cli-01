mend is one command-line tool that applies the edits AI models write, in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files. It follows its specification exactly: three-tier line matching, per-format parse and failure codes, and an all-or-nothing write when any edit fails. Node 22, standard library only.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
